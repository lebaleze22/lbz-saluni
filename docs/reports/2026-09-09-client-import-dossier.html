Client list import/export and individual dossiers

Deployed locally at http://localhost:54321 for Owner and Director accounts.

Import a client list

  1. Open Clients and expand Importer / exporter des clients.
  2. Download the CSV or Excel template. Keep its column headers and add your clients. Use text formatting for phone numbers to preserve country codes and leading zeros.
  3. Select your file and choose Vérifier le fichier. Review the first ten rows, the proposed additions and duplicate count.
  4. If errors are listed, correct the indicated rows and reload the file. Invalid imports write no records.
  5. Choose Confirmer l’import. The final result shows how many clients were added or skipped.

Accepted formats: CSV, XLSX and XLS. Limits: 2 MB, 1,000 client rows and one worksheet per file. Excel formulas must be replaced with values. Larger lists can be split into files.

Column Meaning
Nom Required client name.
Téléphone Optional phone number, preferably stored as text.
Email Optional valid email address.
Sexe Optional femme/homme; F/M and female/male are accepted.
Préférences Optional preferred services, products and habits.
Allergies Optional precautions reported by the client.
Notes Optional internal notes.

English column equivalents are accepted. Unknown or repeated headers are rejected to avoid silently losing information.

Imports use the existing normalized name + phone + email + sex rule. Exact duplicates already in the salon, including archived clients, or repeated inside the file are skipped. Existing profiles and notes are never overwritten. Import confirmation checks again inside a transaction, so a client added after the preview is not duplicated.

Export client lists

In the same panel, select active, archived or all client files, choose CSV or Excel, and click Télécharger. The export includes all records in that status selection; page search filters and pagination do not restrict it.

Exports include coordinates, preferences, allergies and internal notes. Visit and journal histories remain in the individual dossier. CSV exports protect formula-like text, and XLSX cells store client values as text. Exports are not full database backups: internal IDs, archive status, visits and journal entries are not included in the import template.

Use the client dossier

Click a client’s name in the directory to open Dossier client. It brings together:

  • Contact details and editable profile information.
  • Preferences, internal notes and prominently displayed allergies.
  • Visit count and total payments received.
  • Visit history with date, staff member, services, prices, payment methods and recorded product consumption.
  • A dated follow-up journal for consultations, preferences, follow-up and observations.

To add a journal entry, choose a category, enter the event date/time in Douala and write the observation. Each entry preserves its author and creation timestamp. Entries cannot be edited or deleted through the application; add a correction entry when needed. Preference journal entries document changes; update the profile’s preferences field separately to change the current summary.

Visit history and journal entries have independent pagination. Archived dossiers retain their history and journal; restore the client before adding a new observation. The existing Enregistrer une visite button opens the register with that client selected.
