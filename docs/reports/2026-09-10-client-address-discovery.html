Client addresses and discovery sources

Address details, how a client discovered the salon, and who recommended it.

Using the fields

Open Clients and add or edit a client. The new Adresse section contains city, neighbourhood and additional directions. All fields are optional so existing records remain usable.

Under Comment le client a connu le salon, choose the source and add details such as the social network, advertisement or search used.

For a recommendation, either select an existing client or enter the name of another person. The two choices are mutually exclusive. Selecting a different discovery source clears the referral relationship when the profile is saved.

Directory and dossier

The directory includes a Source column and filter, which can be combined with search, active/archived status and visit segments. Each dossier displays the address, discovery source, details and recommender. Linked recommenders open their own client dossier. Archived dossiers retain these details.

The quick register remains focused on visit entry. Complete address and discovery information in the client dossier. The existing name + phone + email + sex duplicate rule is unchanged; address and discovery fields do not create another identity.

CSV and Excel

Download the updated template from the import/export panel. New columns are Ville, Quartier, Adresse, Source, Détails source, ID client recommandant, Nom recommandant. Source codes above and their French interface labels are accepted. Older files containing only the original columns remain supported.

A recommender ID must belong to an existing client in the current salon. It is not resolved by name and cannot refer to a new row in the same import. When transferring data from another salon, use the person's name instead of the foreign ID. Supply either a recommender ID or a name, and set Source to recommendation.

Imports continue to skip exact duplicates without overwriting existing profiles. To add addresses to clients already in the directory, edit their dossiers; re-importing matching clients does not update them.

Integrity and delivery

Database constraints prevent self-referrals, references to another salon, simultaneous linked/free-text recommenders and referral details on a non-recommendation source. The additive migration is 20260909150000_client_address_discovery. Existing clients receive the unknown source by default.
